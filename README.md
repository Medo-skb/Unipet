# 🐶 UNIPET(유니펫) - 반려동물의 모든것!! 🐱

## 💡 프로젝트 소개

**UNIPET(유니펫)**은 반려동물을 키우는 가구의 증가와
관련 서비스에 대한 니즈에 맞춰
반려동물 관련 쇼핑, 병원(진료), 미용, 위탁(호텔/훈련), 커뮤니티를 
하나의 플랫폼에서 종합적으로 안내 및 연계하는 서비스를 제공하고 있습니다.

- 반려동물 용품 쇼핑 (주문, 결제, 배송, 리뷰, 쿠폰 및 포인트)
- 반려동물 서비스 병원(진료), 미용, 위탁(호텔/훈련) 업체 검색 및 예약, 결제, 서비스 완료 후 리뷰 작성
- 서비스 제공 업체는 업체 정보 등록 및 관리 (소개글, 사진, 예약 정책), 예약 및 리뷰 관리 
- (통합/지역) 커뮤니티를 통해 반려동물 관련 정보 공유 및 지역 내 커뮤니티 활동 가능

## ⭐️ 주요 기능

-  쇼핑
    - 카테고리 및 필터 세분화를 통한 상품 검색 용이
    - 동물 (강아지, 고양이, 조류, 어류, 기타) -> (강아지_소형견, 중형견, 대형견)
    - 상품 (식품/영양, 홈/케어, 패션/외출, 놀이/훈련) -> (식품/영양_사료/주식, 간식, 영양제)
    - 동물+상품 필터 조합 가능 (예: 소형견 + 간식)
    - 상품 정렬 기능 (최신순, 가격순, 리뷰수순, 평점순)
    - 상품별 추천 대상 안내 (예: 단모종을 위한 상품)
    - 장바구니, 결제, 환불 기능 제공

-  예약
    - 내 위치 기반 주변 업체 조회 (Kakao 지도 API)
    - 병원/미용실/위탁시설 카테고리별 검색
    - 예약 희망하는 일자 및 시간에 맞춰 예약 가능한 업체 검색하여 조회
    - 유니펫 회원사를 목록 상단에 노출
    - 예약 가능 일자 및 시간 조회 (불가는 일자 및 시간 비활성화)
    - 등록한 반려동물 선택, 진료/서비스 선택하여 예약 및 결제 (예약금은 진료/서비스 금액의 10%)

-  커뮤니티
    - 통합 (일반, 정보/팁, 움짤, 동영상, 질문, 나눔/장터) 게시판 제공
    - 지역 (서울, 인천, 경기 ~ 제주) (산책, 소모임, 여행, 지역정보, 병원추천, 돌봄, 중고거래) 게시판 제공
    - 게시글 정렬 기능 (최신순, 추천순, 조회순, 댓글순)
    - 게시글 임시저장 및 최근임시저장 불러오기, 파일첨부, 비공개글 작성 가능
    - 임시저장 목록 관리 가능
    - 알림 기능 (댓글, 추천 알림)
    - 부적절한 게시글 및 댓글 신고 가능


- 마이페이지 (사용자)
  - 사용자가 이용하는 모든 서비스 정보 조회 및 관리 가능
    - 홈, 구독, 커뮤니티, 주문내역, 예약내역, 반려동물, 포인트, 쿠폰 페이지
    - 홈: 마이페이지 대쉬보드 (내 프로필, 반려동물 프로필, 주문내역 등)
    - 주문내역: 주문 상세 정보 확인 및 제품 리뷰 작성 가능
    - 예약내역: 예약 상세 정보 확인 및 리뷰 작성 가능, 예약 신청 후 결제 미결(예약 대기상태)된 예약 결제 가능
    - 포인트: 포인트 보유 현황 및 사용내역 조회 가능
    - 쿠폰: 쿠폰 보유 현황 (사용가능/완료/만료) 조회 가능
    
- 마이페이지 (사업자)
  - 사업자가 제공하는 서비스 관리 가능
    - 홈, 정보수정, 예약 현황, 리뷰 관리
    - 홈: 마이페이지 대쉬보드 (오늘의 일정, 예약 비율, 예약 건수 그래프)
    - 정보수정: 상세 정보 (소개글, 이미지, 메뉴 등)수정 
    - 예약현황: 오늘 예약, 예약완료, 서비스완료 조회 가능
    - 리뷰관리: 사용자가 작성한 리뷰 조회 및 신고 가능, 전체 리뷰 조회 및 평균 평점 확인 가능
  
- 관리자
  - 신고 관리 (리뷰 및 커뮤니티 신고)
  - 사업자 입점 승인 관리: 사업자 입점 승인/반려 가능
  - 쇼핑몰 문의 답변 관리: 쇼핑몰 상품에 대한 문의 답변 작성 / 문의 삭제 가능
